## 📝 Bahasa Indonesia

Repositori ini merupakan arsip pembelajaran dan proyek selama mengikuti **Pelatihan Pengembangan Web menggunakan Node.js, React.js, dan MySQL** di **BBPVP Bekasi (Balai Besar Pelatihan Vokasi dan Produktivitas Bekasi)**, lembaga pelatihan vokasi nasional di bawah **Kementerian Ketenagakerjaan Republik Indonesia (KEMNAKER RI)**.

Pelatihan berlangsung dalam periode **14 Oktober – 12 Desember 2025**, dengan total **41 hari kerja efektif (363 jam pelatihan)**.  
Kegiatan dilaksanakan **Senin hingga Jumat**, pukul **08.00–17.00 WIB**, mengikuti jam kerja industri.  
**Khusus hari orientasi**, kegiatan berlangsung **08.00–11.00 WIB**.

> 📌 **Catatan jeda (12 – 14 November 2025):**  
> Setelah sesi tatap muka berakhir pada **Selasa, 11 November 2025**, terdapat jeda **Rabu – Jumat, 12 – 14 November 2025** untuk **persiapan Uji Kompetensi** (review materi, perapihan proyek/portofolio, administrasi, dan pembekalan).  
> Jeda ini juga memastikan fase **OJT dimulai pada hari kerja awal pekan (Senin, 17 November 2025)** agar ritme kerja di industri lebih terstruktur.

Pelatihan dibagi menjadi empat tahap utama:

1. **Orientasi Pelatihan**  
   📅 Selasa, 14 Oktober 2025  
   🕗 08.00–11.00 WIB  

2. **Pelatihan Online**  
   📅 15–20 Oktober 2025 (**4 hari kerja efektif**)  
   💻 Materi dasar JavaScript, HTML, CSS, serta konsep web modern.  
   📌 *Rentang tanggal mencakup akhir pekan; sesi efektif berlangsung pada hari kerja.*

3. **Pelatihan Tatap Muka (Offline di BBPVP Bekasi)**  
   📅 21 Oktober – 11 November 2025 (**16 hari kerja**)  
   🏫 Pendalaman Node.js, React.js, REST API, serta pengembangan aplikasi CRUD berbasis proyek menggunakan **MySQL**.

4. **On the Job Training (OJT / Praktek Kerja Lapangan)**  
   📅 17 November – 12 Desember 2025 (**20 hari kerja**)  
   🧰 Penerapan kompetensi web development di lingkungan kerja untuk mensimulasikan proses pengembangan perangkat lunak end-to-end.  
   🗄️ Pada fase OJT, implementasi database menggunakan **PostgreSQL** (menyesuaikan kebutuhan/standar tempat OJT).

   **Ruang lingkup kegiatan utama:**
   - **Pengembangan aplikasi web** menggunakan **Node.js (Express)** dan **React.js** berdasarkan pembagian task dan kebutuhan fitur.
   - **Perancangan dan pengelolaan PostgreSQL**, termasuk pembuatan skema/tabel, relasi, query inti, serta integrasi ke aplikasi.
   - **Implementasi REST API** (struktur endpoint, validasi input, error handling, dan integrasi data) untuk mendukung fitur aplikasi.
   - **Kolaborasi menggunakan Git**: pengelolaan repository, **commit/push/pull**, penggunaan **branching** (feature branch), merge, serta penyelesaian konflik dasar.
   - **Quality improvement**: perbaikan bug, refactoring, penyesuaian UI/UX sederhana, serta peningkatan keterbacaan dan konsistensi kode.
   - **Deployment & hosting** pada **VPS** menggunakan **WHM & cPanel** (setup environment, build aplikasi, konfigurasi domain/subdomain, dan publikasi layanan).
   - **Dokumentasi dan pelaporan**: README, panduan setup, ringkasan fitur, serta logbook/progress report selama OJT.

## 🗣 English

This repository documents my learning journey and project work during the **Web Development Training Program (Node.js, React.js, & MySQL)** at **BBPVP Bekasi (Center for Vocational and Productivity Training)**, managed by the **Ministry of Manpower of the Republic of Indonesia (KEMNAKER RI)**.

The program ran during **October 14 – December 12, 2025**, totaling **41 effective weekdays (363 training hours)**.  
Sessions were held **Monday to Friday, 08:00–17:00 WIB**, following standard industry hours.  
**Orientation day only** was held **08:00–11:00 WIB**.

> 📌 **Gap note (Nov 12 – 14, 2025):**  
> After the on-site sessions ended on **Tuesday, November 11, 2025**, there was a gap on **Wednesday – Friday, November 12 – 14, 2025** dedicated to **Competency Test preparation** (material review, project/portfolio polishing, administrative tasks, and briefing).  
> This gap also ensured that the **OJT phase started on a Monday (November 17, 2025)** to align with a structured workplace schedule.

The program was divided into four main phases:

1. **Orientation**  
   📅 October 14, 2025  
   🕗 08:00–11:00 WIB  

2. **Online Training**  
   📅 October 15–20, 2025 (**4 effective weekdays**)  
   💻 Focused on JavaScript fundamentals, HTML, CSS, and modern web concepts.  
   📌 *The date range includes a weekend; sessions took place on weekdays only.*

3. **Offline Training (On-site at BBPVP Bekasi)**  
   📅 October 21 – November 11, 2025 (**16 weekdays**)  
   🏫 Covered Node.js, React.js, REST API, and project-based CRUD application development using **MySQL**.

4. **On the Job Training (OJT)**  
   📅 November 17 – December 12, 2025 (**20 weekdays**)  
   🧰 Hands-on industry-style practice applying web development competencies in an end-to-end software delivery workflow.  
   🗄️ During OJT, the database implementation used **PostgreSQL** (aligned with the host workplace requirements).

   **Key activities:**
   - **Web application development** using **Node.js (Express)** and **React.js**, delivered through task-based execution.
   - **PostgreSQL database design and management**, including schema/table creation, relationships, core queries, and application integration.
   - **REST API implementation** (endpoint structuring, input validation, error handling, and data integration) to support application features.
   - **Git-based collaboration workflow**: repository management, **commit/push/pull**, **branching** (feature branches), merging updates, and basic conflict resolution.
   - **Quality improvements**: bug fixing, refactoring, minor UI/UX adjustments, and code consistency/readability enhancements.
   - **Deployment & hosting** on a **VPS** using **WHM & cPanel** (environment setup, application build, domain/subdomain configuration, and service publication).
   - **Documentation and reporting**: README, setup guide, feature summary, and OJT progress logbook/report.

- JavaScript (ES6+)
- Node.js (Express.js)
- React.js

- HTML & CSS

**During OJT (Industry practice):**
- **PostgreSQL** (database implementation)
- Git workflow (**commit / push / pull / branching / merge**)
